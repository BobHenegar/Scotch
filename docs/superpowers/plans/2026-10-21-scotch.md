# Scotch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved Windows clock in BobHenegar/scotch.

**Architecture:** WPF window and Windows adapters surround a platform-independent movement state machine. UI-thread updates consume monotonic elapsed time, pointer position and display geometry; settings remain local.

**Tech Stack:** C#, .NET 10 LTS, WPF, WinForms NotifyIcon, Win32 interop, System.Text.Json, xUnit, GitHub Actions Windows runner.

**Spec:** ../specs/2026-10-21-desktop-clock-design.md

## Global Constraints
- Windows only; native C# desktop application.
- No backend, accounts, telemetry, or network dependency.
- One clock, one home monitor, local time, optional date, avoidance toggle, saved home, theme integration, and tray controls.
- Home padding 16 DIP; avoidance margin 48 DIP; yield about 200 ms; return delay one second and return duration about two seconds.
- Ctrl+Alt+C toggles avoidance; startup defaults off; avoidance starts enabled.
- Preserve foreground focus during automatic movement. Use Windows app theme, accent, live changes and contrast colors.

## Review Focus
- Mixed DPI and negative monitor coordinates: pointer and window geometry must share a coordinate system.
- Pointer parked at home or on return path: clock must stay clear without oscillation.
- Corrupt/non-finite saved coordinates and disconnected displays: recover inside the primary work area.
- Held hotkey and unavailable registration: toggle once per press; retain tray access.
- Resume after sleep and Explorer restart: avoid large animation jumps and restore tray access.

- `src/Scotch.Core/Scotch.Core.csproj`: net10.0, no desktop dependencies.
- `src/Scotch.Core/Geometry.cs`: PointD, SizeD, RectD records in DIP.
- `src/Scotch.Core/MovementController.cs`: avoidance and return state.
- `src/Scotch.Core/ClockSettings.cs`, `SettingsStore.cs`: validated preferences and atomic JSON writes.
- `src/Scotch/Scotch.csproj`: net10.0-windows WPF WinExe, WinForms enabled, explicit namespace aliases.
- `src/Scotch/App.xaml`, `App.xaml.cs`: lifecycle and per-user single-instance guard.
- `src/Scotch/ClockWindow.xaml`, `ClockWindow.xaml.cs`: presentation, timer, drag and controller wiring.
- `src/Scotch/Windows/NativeMethods.cs`, `MonitorService.cs`, `HotkeyService.cs`, `ThemeService.cs`, `TrayService.cs`, `StartupService.cs`: focused adapters.

- `tests/Scotch.Windows.Tests/`: adapter/presentation tests on Windows using an STA test helper.
- `.github/workflows/build.yml`, `README.md`, `docs/manual-validation.md`: verification, packaging and user instructions.
